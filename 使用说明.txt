========================================
  RlyehBot - 肉鸽模式自动脚本 使用说明
========================================

【脚本功能：
  自动运行邪神戦記ルルイエ少女隊的肉鸽模式（アポカリプスモード）
  支持自动选择角色、关卡、Buff/Debuff、装备
  支持自动战斗、自动领奖、自动重开

========================================
  第一步：安装环境准备
========================================

1. 安装Python（如果还没装过Python，去官网下载：https://www.python.org/downloads/
   安装时记得勾选 "Add Python to PATH"

2. 安装依赖库
   双击 install_deps.bat
   等待安装完成

========================================
  第二步：截取模板截图
========================================

1. 打开游戏并登录游戏，进入肉鸽模式界面

2. 双击 run_vision.bat 启动脚本

3. 切换到【模板管理】标签页

4. 选择目标分类，点击【截图 (3秒延迟)】按钮
   - 点击后3秒内切换到游戏窗口
   - 用鼠标拖拽框选对应的按钮/图片
   - 松开鼠标自动保存

5. 重要模板分类（按顺序截取）:
   ├─ menu: 主菜单上进入肉鸽的按钮
   ├─ start_apoc: 开始挑战按钮
   ├─ confirm: 确认/决定按钮
   ├─ close: 关闭弹窗按钮
   ├─ character: 角色选择卡片
   ├─ stage_boss: Boss关卡图标
   ├─ stage_elite: 精英关卡图标
   ├─ stage_normal: 普通关卡图标
   ├─ buff: Buff增益（恩寵）选项
   ├─ debuff: Debuff减益选项
   ├─ equipment: 装备选择图标
   ├─ reward: 奖励领取按钮
   ├─ victory: 胜利画面按钮
   ├─ defeat: 失败画面按钮
   ├─ restart: 重新开始按钮
   ├─ error_500: 500网络错误弹窗
   ├─ error_retry: 错误重试/重新进入游戏按钮
   └─ common: 其他通用确认按钮

6. 为每个模板设置优先级
   - 选中模板，点击【设置优先级】
   - 数字越大，越优先被选择
   - 例如：3个Buff模板，优先级10的会被优先点击

========================================
  第三步：设置优先级
========================================

切换到【肉鸽流程】标签页：

关卡选择优先级（数字越大越优先选）:
  - Boss关: 10（默认最高，建议）
  - 精英关: 8
  - 事件关: 6
  - 商店关: 5
  - 普通关: 3

切换到【设置】标签页还可以调整：
  - 识别置信度（默认0.8，识别不准就调低）
  - 点击延迟
  - 最大轮数
  - 等等

========================================
  第四步：启动脚本
========================================

1. 确保游戏在肉鸽模式界面
2. 切换到【主页】标签
3. 点击【启动肉鸽脚本】
4. 快速切回游戏窗口
5. 脚本会自动运行

停止方法：
  - 按 Ctrl+Alt+Delete 打开任务管理器结束Python
  - 或把鼠标快速移到屏幕左上角（pyautogui安全机制）

========================================
  肉鸽模式完整流程
========================================

脚本会自动识别并执行以下流程：

1.  主菜单 → 点击进入肉鸽模式
2.  开始确认 → 确认开始挑战
3.  角色选择 → 选择出战角色（按模板优先级）
4.  关卡选择 → 选择路线（Boss>精英>事件>商店>普通）
5.  战斗中 → 自动战斗，自动加速
6.  战斗结算 → 领取奖励
7.  Buff选择 → 选择增益效果（按模板优先级）
8.  装备选择 → 选择获得的装备
9.  重复步骤4~8直到Boss关
10. Boss战 → 击败最终Boss
11. 通关结算 → 领取通关奖励
12. 自动重开 → 重新开始新一轮

========================================
  注意事项
========================================

1. 游戏窗口必须在前台可见，不能最小化
2. 游戏分辨率最好保持不变
3. 如果识别不准，把置信度调低（如0.75）
4. 模板截图越精准（框选越小越好
5. 每个分类多截几个不同状态的模板提高识别率
6. 首次使用建议先手动看着跑一轮确认没问题
